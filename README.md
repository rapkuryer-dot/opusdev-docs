# OPUSDEV

**OPUSDEV** is a browser-based 3D exploration game on a tiny stylized planet.  
Walk, jump, and look around in any modern browser — no install required.

## Play

**[https://opusdev.org](https://opusdev.org)**

Source deploy: [rapkuryer/opusdevgame](https://github.com/rapkuryer/opusdevgame) on [Vercel](https://vercel.com).

## Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Mouse | Look around (360°) |
| Space | Jump |
| E | Interact |

Works on desktop and mobile (virtual stick + touch look).

## About

- **Engine:** Three.js (WebGL)
- **Style:** Cel-shaded anime world
- **World:** Spherical planet with water, foliage, and city details
