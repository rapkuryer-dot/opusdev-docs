# OPUSDEV

**OPUSDEV** is a browser-based 3D exploration game on a tiny stylized planet.  
Walk, jump, and look around in any modern browser — no install required.

## Play

The live build is hosted on Vercel (connected to the private deployment repository).

## Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Mouse | Look around (360°) |
| Space | Jump |
| E | Interact |

Works on desktop and mobile (virtual stick + touch look).

## About

- **Engine:** Three.js (WebGL)
- **Style:** Cel-shaded anime world inspired by messenger.abeto.co
- **World:** Procedural planet assembly, water, foliage, city signs
