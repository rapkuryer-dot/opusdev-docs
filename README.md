# OPUSDEV

**OPUSDEV** is a browser 3D exploration game on a tiny stylized planet.  
Built with **Three.js** (WebGL) and **three-mesh-bvh** — walk, jump, and explore in any modern browser, no install.

On play, the world **materializes block by block**: hills, streets, trees, and buildings fly in and snap together as you move.

## Play

**[https://opusdev.org](https://opusdev.org)**

Source deploy: [rapkuryer/opusdevgame](https://github.com/rapkuryer/opusdevgame) on [Vercel](https://vercel.com).

## Controls

| Input | Action |
|-------|--------|
| WASD | Move |
| Mouse | Look around (360°) |
| Space | Jump |
| E | Interact |

Works on desktop and mobile (virtual stick + touch look).

## About

- **Engine:** Three.js (WebGL)
- **Style:** Cel-shaded anime world
- **World:** Spherical planet with water, foliage, and city details
